# AI-Powered Wi-Fi Signal Strength Heatmapper
An Intelligent Mobile Diagnostic Platform for Campus Network Auditing

**Student:** Yong Ken (BSSE2506025)
**Supervisor:** Mr Eric Kong Kok Wah
**Module:** MAL3018 Computing Project

## Vision
A free, offline Android app that lets campus IT technicians tap their position on a floor plan, record Wi-Fi signal strength, and see a heatmap of weak spots and dead zones. An on-device AI model fills in unmeasured areas, shows how confident it is, and suggests where to scan next.
